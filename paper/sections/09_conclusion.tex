\section{Conclusion}

We formulated autonomous merchant search as exact finite-horizon stopping with
hard time, token, API-call, API-spend, and purchase-price constraints.  Remaining
resources are part of the Bellman state, and the purchase cap restricts the
admissible action set.  On the registered synthetic benchmark, binding resource
regimes change the action for the same offer.

The current Python implementation atomically reserves enforceable per-call
permits, conservatively reconciles censored usage, and provides frozen-panel
oracle metrics and UCP inventory screening.  These are implementation steps, not
the paper's result.  The joint merchant-and-permit solver, calibrated UCP panels,
paired policy comparison, JavaScript receipt parity, and safety proof remain
open before the contribution can be evaluated.
