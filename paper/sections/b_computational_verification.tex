Run \texttt{make install}, \texttt{make build}, and \texttt{make check} from the
repository root to install dependencies, regenerate JSON, CSV, \LaTeX{}, site,
claim, and conformance artifacts, and verify both packages.  The npm checks cover
the planner and middleware against vectors generated by the canonical Python
implementation.  The analysis uses exact rational arithmetic; the hard-constraint
checks have no floating tolerance.  Generated manifests omit wall-clock timestamps
and record the configured seed
\ResultRandomSeed{}.

The current unit checks cover offer expiry, resource exhaustion, hard-cap
admissibility, budget-dependent Bellman actions, atomic reservation, exact
reclamation, conservative censored charging, one-time reconciliation,
commerce-domain validation, frozen-panel oracle metrics, endpoint-inventory screening,
deterministic artifact generation, and claim evaluation.  JavaScript receipt
parity and exhaustive independent policy enumeration on reduced joint-action
horizons remain required checks rather than completed verification results.
