# Autonomous Shopping Optimizer

Browser-safe hard-budget optimizer middleware for autonomous shopping loops. Install
`autonomous-shopping-optimizer`; the host owns LLM calls, merchant tools,
credentials, and purchase execution. Planner behavior is checked against conformance
vectors generated by the canonical Python package. Call `nextQueryPermit()` before
dispatch, enforce its `timeout`, `maxTokens`, `maxApiCalls`, and `maxApiSpend` ceilings,
then pass actual usage to `observe()`.

The current npm release covers the existing planner and completed-call middleware
contract. The Python package now has an atomic reservation receipt and censored-usage
reconciliation lifecycle; equivalent JavaScript behavior and generated conformance
vectors are still pending. Do not treat the current JavaScript accounting path as
proof of pathwise budget safety.
